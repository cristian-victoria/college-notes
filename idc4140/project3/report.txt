[Introduction]
        This project utilizes Machine Learning techniques to classify dermoscopic skin lesion images using the DermaMNIST dataset. This dataset is a standardized benchmark containing 7 diagnostic categories. I utilize two classification approaches: a Logistic Regression model, which treats each flattened image as a feature vector, and a Neural Network, which learns non-linear representations through multiple layers of transformations. Both models are evaluated on validation and test sets using accuracy and per-class F1 score. The goal of this report is to assess the trade-offs between model simplicity and performance in the context of multi-class biomedical image classification.

[Logistic Regression results]
Why is Logistic Regression a linear model? Because it makes predictions by computing the weighted sum of the input features, which is a linear operation. The computation is as follows: z=Wx+b; where W is a weight matrix, x the flattened image vector, and b a bias term. The activation function is applied after, but the linearity remains. 
What are its limitations for image data? When applied to images, Logistic Regression is limited because it has no spatial awareness. By flattening each image into a 1D vector, the model doesn’t gain a capacity to understand how neighboring pixels are related to each other. It also cannot learn complex patterns. Since it is a linear model, it cannot capture non-linearity.

[Step-by-step explanation]
        Input Representation? Each DermaMNIST image starts as a (3, 28, 28) tensor. The 3 refers to the 3 colour channels of RGB, which are at 28x28 pixels. This is fed into the network and flattened into a single 1D vector of 3*28*28=2352 values using images.view(images.size(0), -1). The pixels have already been normalized during preprocessing via transforms.Normalize(), and as such no pixel dominates. 
        Architecture Design? The network consists of two fully connected layers: fc1 and fc2. The former maps the 2352 input features to 128 hidden neurons, and the latter maps the 128 hidden neurons to 7 output scores (one per class). This gives a total of (2352*128+128)+(128*7+7) = 302,087 trainable parameters.
Activation functions? I chose ReLU as my activation function which is applied to the first linear layer (fc1). It sets all negative values to zero and keeps the positive values unchanged, ensuring there is non-linearity in the model. The next step handles the final activation function, softmax, to fc2.
Forward Pass? The forward pass is defined as: x (2352,) → fc1 → z1 (128,) → ReLU → a1 (128,) → fc2 → z2 (7,). The output that z2 contains, the 7 raw logit scores, each represents a class. 
Loss function? I’ve used CrossEntropyLoss() to apply softmax internally to convert the 7 raw logits into probabilities, then compute how far those probabilities are from the true label. The loss computation is what drives the weight updates so that the incurred losses are minimized as much as possible.
Backpropagation? After the loss is computed, loss.backward() computes the gradient for every trainable parameter in the network using the chain rule, propagating the error signal backwards from the output layer through to the input layer. 
Training Process? Training runs for 20 epochs, with a batch size of 128. Each epoch has two phases: a training phase and a validation phase. The training phase updates the weights after loss is computed and backpropagated. The validation phase serves as an unbiased check on how well the model is generalising to data it has never been trained on. It allows for overfitting to be detected and gives valuable information on which hyper parameters we can tune later to increase final model performance. 
Evaluation metrics? After training, the model is evaluated on the test set using two metrics from sklearn: accuracy_score and classification_report. Accuracy_score gives the overall proportion of correct predictions (71%)], while classification_report gives per-class precision, recall, and F1-score. Precision measures how often a positive prediction is correct, recall measures how many true positives were found, and F1 is the mean of the two.

[Comparison]
        Which model performed better? Both the Logistic Regression model and the Neural Network model achieved a very close test accuracy (69% and 71% respectively). However, the differences are clearer on other metrics. For example, the macro F1 is more significant (0.36 to 0.41). This suggests that the Neural Network represents the minority classes more genuinely than the Logistic Regression model does, and therefore the Neural Network can be said to be the better model.  
        Which generalized better? Neither model generalises particularly well, but the Neural Network shows slightly better generalisation than the Logistic Regression model. This is due to its non-linearity compared to the linearity of the Logistic regression, allowing the Neural Network to learn the complex and nonlinear boundaries between classes.
        Why do neural networks perform better on images? As mentioned before, the Neural Network has a non-linearity principle which makes it better than the logistic regression model. Even with just having two layers, it is also far more expressive than Logistic Regression’s simple weighted sum. 
        What are the risks in medical applications? The class imbalance is a serious concern. The models correctly identify only a few of the minority classes, while the majority classes are strongly predicted. Therefore, even if the model accuracy of 71% is misleading. Moreover, in medical applications, a prediction has an impact on the kind of diagnoses a patient receives. If the patient receives the wrong treatment, then it can have serious side effects from the treatment itself. This is also in addition with the fact that the actual problem the client is facing will not be treated properly, and that will also have adverse effects too. That is why, even if the model accuracy were actually 71%, this is unacceptable and data scientists should aim for greater accuracy (for example, over 90%). Lastly, neither model clearly explains why it made a prediction. This lack of interpretability is a key concern for clinicians because they want to understand the reasoning behind a diagnosis, not just receive a class label. 


[Conclusion]
This report explored two approaches for classifying skin lesion images from the DermaMNIST dataset: a Logistic Regression and a Neural Network. Both models achieved comparable overall test accuracies of 69% and 71% respectively. However, these figures are misleading given the severe class imbalance in the dataset, with melanocytic nevi accounting for approximately 67% of all samples. The neural network demonstrated a clear advantage in its ability to learn non-linear representations, reflected in its higher macro F1 score of 0.41 compared to 0.36 for Logistic Regression. That said, both models fall short of the standard required for a medical application. This is because its most limiting factor, the class imbalance of the dataset.
