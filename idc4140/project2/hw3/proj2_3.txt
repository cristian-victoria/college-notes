Part 2 - Why did I pick label encoding? 

Because KNN computes distances between points, Label encoding keeps dimensionality low and managable by keeping one column per feature.

Part 8 - Written Analysis

Preprocessing Decisions = 

As aforementioned, label encoding was chosen. 
Invalid entries were given by ? which were replaced with NaN and dropped.

Effect of Scaling = 

Standard Scaler was applied to all features, ensuring that every feature contributed equally to neighbor distances.

Best k = 

The best k was 7. This was selected based on the highest F1 score across all k values. 
F1 was selected to mitigate the impact of class imbalance which was present in the dataset. 

Strengths of KNN = 

KNN is simple to implement once you understand the concepts and how to use the libraries. 
It is also non-parametric in that it makes no assumptios about the underlying data distribution.

Weaknesses of KNN = 

However, KNN can be sensitive to redundant features as well as class imbalance. It also does not give context
on why the prediction was made. 

Challenges in dataset = 

There were multitude invalid entries. There was also a staggering class imbalance. There were also mixed feature types (6 numeric and 8 categorical), which needed to be accounted
for during preprocessing.
