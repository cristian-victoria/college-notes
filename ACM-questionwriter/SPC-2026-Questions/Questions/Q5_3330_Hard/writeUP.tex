\section{Disaster at the Space Station}

Oh no! You are currently aboard the International Space Station when a meteor strikes, causing severe damage to the exterior and scattering the crew throughout the station. You manage to reach the control center, but several crew members are now missing.

With oxygen levels rapidly decreasing, time is critical. Each missing crew member has a recorded oxygen level percentage and a distance from the control center. 
To maximize survival, you must determine the order in which to rescue the crew members.

To assist in this emergency, you are tasked with writing a program that organizes and reports the missing crew members based on rescue priority.

\subsection{Input}

The input consists of a single integer $N$ that represents the number of astronauts on board followed by $N$ lines. 
\newline \newline Each line holds astronaut information and is as follows:
\begin{itemize}
    \item A string $S$, the astronaut's name
    \item An integer $K$, the astronaut's oxygen level
    \item An integer $D$, the distance from main cabin
\end{itemize}

\subsection{Output}

Print two sections - Critical and Non-Critical. Based on their oxygen level, print out the corresponding astronauts. Critical levels are anything below 30\%. If a tie in oxygen level, compare their distances.
