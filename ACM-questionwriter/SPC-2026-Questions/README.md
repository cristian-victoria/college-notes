# SPC-2026-Questions
**Question Packets for the Spring 2026 Programming Contest**

## Guidelines
Write each question's solution, input, and output files in their respective folders (i.e. Q1_3014 is for question one, etc).

Executables or any other files related to the question are not to be included here. Contact the Programming Contest Chair on Discord if you have any questions.

### Acceptable Languages
C, C++, Python, Java, CSharp

### Question Write-Ups
All question write-ups must include one to two paragraphs of problem description, a written input descirption, a written output description, and a simple input example with corresponding outputs.

Problem descriptions must be student appropriate. Do not hesitate to contact us for support with these write-ups.

### Tools
[BAPCtools](https://github.com/RagnarGrootKoerkamp/BAPCtools) - a tool for creating and developing problems following the CLICS (DOMjudge/Kattis) problem format

### File Naming Formats

#### Code Solution
code.cpp, code.py, etc.

#### Input
in< number >.txt

(Ex: in1.txt)

#### Output
out< number >.txt

(Ex: out1.txt)
